# 🚀 Blog App Backend (Node.js)

**A robust and scalable backend for a modern blog application, following best practices in API development, security, and performance.**

### 🔗 Frontend Repository

## The frontend for this project is available **[[HERE](https://github.com/ishantrivedi25/blog-app-frontend-react)]**

## 🚀 Features

- 📌 **MVC Architecture** – Follows a modular structure ensuring clean, maintainable, and scalable code.
- 🔐 **Secure Authentication & Authorization** – Implements JWT & secure cookies for a safe and seamless authentication/authorization experience.
- ⚡ **Type-Safe Development** – Fully built with TypeScript to enhance code quality and prevent runtime errors.
- ⏳ **Advanced Rate Limiting** – Protects APIs from abuse and brute-force attacks with optimized request throttling.
- 🛡️ **Enhanced Security Measures** – Configured CORS, Helmet, and other best practices to prevent vulnerabilities.
- 📦 **Efficient Database Integration** – Uses MongoDB with Mongoose for robust and flexible data management.
- 🌱 **Built-in Data Seeding** – Allows seamless setup of initial application data for testing and development.
- 📝 **Comprehensive Logging** – Structured logging with Winston for efficient debugging and monitoring.
- ✅ **Robust Validation & Sanitization** – Enforced with Zod to ensure data consistency and security.
- ❌ **Global Error Handling & 404 Responses** – Provides standardized error handling across all API endpoints.
- 📏 **Industry-Standard API Practices** – Implements proper methods, query parameters, path parameters, and status codes.
- 🔄 **Graceful Server Shutdown** – Ensures proper resource cleanup and prevents memory leaks on server termination.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, TypeScript, Express.js
- **Database:** MongoDB with Mongoose
- **Authentication:** JWT & Secure Cookies
- **Validation:** Zod
- **Logging:** Winston

## 📦 Installation & Setup

### 1️⃣ Clone the repository

```sh
git clone https://github.com/ishantrivedi25/blog-app-backend-nodejs.git
cd blog-app-backend-nodejs
```

### 2️⃣ Install dependencies

```sh
npm install
```

### 3️⃣ Set up environment variables

Create a `.env` file and add the required variables:

```sh
JWT_SECRET=your-secret-token
MONGODB_URL=your-mongodb-url
PORT=3000
CLIENT_URL=your-frontend-url
```

### 4️⃣ Start the project

```sh
npm run dev
```
